# Acknowledgements

This project is maintained by `mimaowang` with contributions from the `econ-reference-matcher` community.

`econ-reference-matcher` is designed for compatibility with Claude Code style skills and agent workflows. Its structure is informed by common Agent Skill conventions: a concise `SKILL.md`, progressively disclosed reference files, and deterministic helper scripts for repeatable checks.

The benchmark hygiene and repository-quality checklist are informed by widely used open-source project practices, including GitHub community profile conventions and OpenSSF Scorecard-style concerns such as CI, security policy, dependency hygiene, and reproducible validation.

This repository does not bundle proprietary SSCI, JCR, ABS/AJG, FT50, UTD24, Web of Science, Scopus, or publisher database content. Example papers, DOIs, journals, and benchmark candidates are fictional unless explicitly stated otherwise.

Retrieval guidance draws on the official RePEc, AEA EconLit, OpenAlex, Crossref, and Semantic Scholar documentation linked in `references/workflow.md` within the skill. These links describe external services, not endorsements or bundled access. No provider code or datasets are included.

If future versions incorporate code, datasets, benchmark cases, or substantial ideas from external projects, add those projects here with their license terms and links.
